HemoSense AI
Smartphone anemia screening from an eye (conjunctiva) photo, using fuzzy logic, with personalised diet plans
Platform: Flutter (Android)  ·  Backend: Python (FastAPI / Flask) + OpenCV + scikit-fuzzy
Input: photo of the lower inner eyelid + basic profile (age, sex, diet)
Output: anemia risk level, estimated Hb range, explanation, diet & meal plan

⑧ Review & crop (ROI)

  • User checks the photo and adjusts the region of interest box on the conjunctiva.
  • The ROI coordinates are sent with the image, so the backend can skip automatic segmentation or use it as a check.
  • The quality score is computed on the device before upload.
  • A low score sends the user to screen ⑯.

⑰ Profile & settings

  • Edit the health profile, which affects thresholds and diet.
  • Reminders, language and privacy controls.
  • Developer section: backend URL with a status check, useful when the laptop's IP changes during demos.
Decisions for review
  1. Login: required, optional (guest mode as shown), or none? Firebase Auth or our own Python auth?
  2. Profile data: keep age, sex and pregnancy for WHO thresholds? Add weight or known conditions?
  3. Capture: one eye per scan, or both eyes averaged? Use flash or not?
  4. ROI: manual crop box (⑧), automatic segmentation on the backend, or both?
  5. Result: show the estimated Hb number, or only the risk category (safer if the model isn't calibrated)?
  6. Explainability (⑪): show to all users or only in developer mode?
  7. Diet: Indian/regional food focus? Which food database? Include the 7-day plan in v1?
  8. Extras for v1: PDF report, nearby labs, reminders, multiple languages (English/Hindi/Telugu)?
  9. Storage: history on the device only, or also in a backend DB (SQLite/PostgreSQL)? Keep or delete images?
  10. Optional add-on: a short symptom questionnaire (fatigue, dizziness) as an extra fuzzy input to improve accuracy?
Next step: once these are decided, I'll create the Flutter project with these screens and the Python backend skeleton.
